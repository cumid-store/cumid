# CUMID visual system

Use the non-text Notebook Bird symbol in public/brand/logo-mark.svg. The mark uses dark lavender #756284 and sage #596B58. The footer variant is logo-dark.svg. The older wordmark asset is not used.

Website: ivory #F7F4EF, charcoal #252321, lavender #62537D for readable accents, soft sage for section backgrounds. System sans-serif for interface text; Georgia italic is limited to the homepage headline. No remote font dependency.

Let cover artwork carry the colour. Use square media, thin separators, restrained corners, descriptive labels and plain copy. Avoid glowing shapes, floating promotional labels, invented reviews, fake urgency, repetitive badges and long brand manifestos.

Use original cover artwork, never promotional Instagram graphics as product photos. Design previews must remain labelled. The current web images are optimised derivatives, not print masters; retain the original high-resolution source files for print production. Source paths are in CATALOGUE_SOURCES.json. Four minimal concepts appear as gallery alternatives, not separate confirmed inventory.
